# Chữ của trang logo và bộ biểu tượng

Bảng do `rang/words.mjs --write-table` viết từ khuôn chữ của plugin 0.76.0 và `design/book-words.json`; `rang/words.mjs`
so lại mỗi lần chạy. Không sửa tay.

| Khoá | Khuôn (tiếng Anh) | Sổ (tiếng Việt) |
| --- | --- | --- |
| `brandTitle` | Brand assets | Logo và bộ biểu tượng |
| `brandQuestion` | Which mark the product carries, and which icons it draws with | Sản phẩm mang logo nào, và vẽ bằng bộ biểu tượng nào |
| `brandLede` | Each file of the mark is drawn here from the file the repository pins, by its role and its variant; the icon set is named with what its row records. Nothing on this page is drawn by the book. | Mỗi tệp logo được vẽ ở đây từ đúng tệp mà kho ghim, theo vai trò và biến thể của nó; bộ biểu tượng được nêu tên cùng những gì dòng của nó ghi. Sổ này không tự vẽ gì trên trang này. |
| `brandMark` | The mark | Logo |
| `brandIcons` | The icon set | Bộ biểu tượng |
| `brandFloorText` | The mark is the floor's text: the product's name set in the heading typeface, and no file. | Logo ở mức tối thiểu là chữ: tên sản phẩm đặt bằng phông tiêu đề, không kèm tệp nào. |
| `brandNoIcons` | No icon set is recorded yet. | Chưa ghi bộ biểu tượng nào. |
| `brandRow` | row | dòng |
| `brandPin` | pins | ghim |
| `brandSizes` | sizes | cỡ |
| `brandNoSizes` | no sizes recorded | chưa ghi cỡ nào |
| `brandStroke` | stroke | nét |
| `brandUnread` | the file cannot be read | không đọc được tệp |
