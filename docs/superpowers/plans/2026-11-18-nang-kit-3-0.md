> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move the repo from acceptance kit v2.38.1 (`phanlemanh/acceptance-gate-kit`) to v3.0.0 (`phanlemanh/delivery-loop`) so CI, the Claude Code session and `kit-root` use one kit at one tag.

**Tech Stack:** Node 24 ESM (`.mjs`), Vitest for `tests/kit-root.test.ts`, `node --test` for the two-way file, git worktrees in `os.tmpdir()`.

**Spec:** `docs/superpowers/specs/2026-11-18-nang-kit-3-0-design.md`; contract `_acceptance/nang-kit-3-0/contract.md`; evals `_acceptance/nang-kit-3-0/evals.yaml` (pinned messages are copied from there, verbatim).

- No network / tag missing: every measure that fetches a kit exits non-zero with `kit: cannot fetch <url> <tag>`, never green.
- Gate prints exit 0 without `pre-merge-check: rules ran=`: measure is red (`gate-branch: no rules ran`).

- Temp worktrees left behind after a red run: every measure removes its worktree in `finally` (`git worktree remove --force`); two-way checks `git worktree list` has no `nk30-` entry after the run.
- merge-base equals the fixed baseline: `gate-control` prints one line with `merge-base is 8925e8ff`.
